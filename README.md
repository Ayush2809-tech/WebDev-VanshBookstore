# WebDev-Project--VanshBookstore-
===========================================================
                 ONLINE BOOKSTORE WEBSITE
===========================================================
-----------------------------------------------------------
📌 INTRODUCTION
-----------------------------------------------------------

This project is a simple Online Bookstore website designed
using HTML, CSS, and JavaScript. It includes essential web
pages like Home, Catalogue, Cart, Login and Registration.

The main purpose of this project is to demonstrate website 
UI design and JavaScript validation techniques.

-----------------------------------------------------------
🎯 OBJECTIVES
-----------------------------------------------------------

✔ Create a multi-page website  
✔ Apply modern UI styling (Glass Effect, Gradient Background)  
✔ Handle form input and validation using JavaScript  
✔ Build user-friendly Login & Registration pages  
✔ Demonstrate front-end development skills  

-----------------------------------------------------------
🛠 TECHNOLOGIES USED
-----------------------------------------------------------

• HTML – Page structure  
• CSS  – Styling & Layout (Glassmorphism UI)
• JavaScript – Form validation & logic

✅ FEATURES IMPLEMENTED
-----------------------------------------------------------

• Password length validation  
• Error message display  

-----------------------------------------------------------
🧪 FORM VALIDATION RULES
-----------------------------------------------------------

Registration Page:
- Name must contain at least 3 characters
- Valid email format using regex check
- Password must be minimum 8 characters

Login Page:
- Email and Password required
